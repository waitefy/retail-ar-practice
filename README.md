# Разработка приложений дополненной реальности для розничной торговли

Учебная практика

Автор: Линьков Матвей Вадимович

Группа: ИКБО-31-24

В работе исследуется дистанционное ознакомление покупателя с товаром
и предварительный выбор его варианта. Дополненная реальность рассматривается
как дополнительный способ увидеть товар вместе с реальной обстановкой
или изображением покупателя.

Обзор охватывает несколько применений AR в розничной торговле. Подробным
примером служит виртуальная примерка декоративной косметики и сравнение
оттенков помады. На нём описываются действия покупателя, данные каталога
и работа визуализации.

В проекте описаны работа с товарами и вариантами, подготовка параметров
визуализации и цветовое наложение на изображение. Модель процесса,
демонстрационный каталог и контракты функций задают данные и правила обработки.
