# Работа с каталогом

Язык — Python; проверенная версия — **3.14.7**. Используется только
стандартная библиотека, установка пакетов не требуется. Программа состоит
из функций и стандартных структур данных, собственных классов нет.

Реализована операция BPMN «Предоставить сведения о варианте»:
`get_variant_details(catalog, variant_id)` возвращает товар, вариант,
оттенок и связанные материалы в порядке показа. Структура каталога
соответствует [логической модели](../models/er_logical.drawio).

Файлы: [catalog.py](catalog.py) — загрузка, проверка и консольный запуск;
[results.py](results.py) — общий формат результата;
[catalog_checks.py](catalog_checks.py) — проверки;
[data/catalog.json](data/catalog.json) — демонстрационные данные.

## Запуск

Из корня репозитория:

```bash
python --version
python src/catalog.py --variant V001
```

Вывод — JSON с полями `ok`, `data`, `error`. Для V001 ожидаются товар P001,
артикул DEMO-001, оттенок S001 «Розовый» с RGB (190, 90, 120) и материалы
M002, M001 в указанном порядке. `data` содержит `product`, `variant`,
`shade`, `materials`; каждый материал включает свою роль и порядок показа.
Каталог учебный: товар вымышленный, ссылки на retail-ar.example служат
обозначениями страницы и материалов. Сетевых запросов нет.

По умолчанию выбирается V001. Путь к каталогу определяется относительно
`catalog.py`, поэтому запуск возможен из другого рабочего каталога.
Свой файл задаётся параметром `--catalog`:

```bash
python src/catalog.py --catalog src/data/catalog.json --variant V003
```

Перед выдачей сведений проверяются пять коллекций, состав полей, значения,
уникальность ключей и артикулов, внешние ключи и порядок материалов.
Входные данные не изменяются, результат содержит копии записей.
Успех — код завершения `0`. Ошибки выводятся в `stderr`, код — `1`:
`catalog_read_error` — файл не прочитан; `invalid_catalog` — неверные данные;
`invalid_variant_id` — пустой идентификатор; `variant_not_found` — вариант
отсутствует. Например, `--variant V999` возвращает последнюю ошибку.
Неверные аргументы командной строки обрабатывает `argparse`, код — `2`.

## Проверка

```bash
python -m py_compile src/results.py src/catalog.py src/catalog_checks.py
python src/catalog_checks.py
```

Ожидаемый итог: `Пройдено групп проверок: 7`. Проверяются ключи и ссылки,
ограничения значений, связь M:N и порядок материалов, копирование записей,
ошибки JSON и консольный запуск из другого каталога. Проверки запускаются
без флага `-O`, который отключает `assert`.
